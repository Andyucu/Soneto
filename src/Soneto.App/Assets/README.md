# Assets

`tray-icon.ico` is a **placeholder tray icon**, generated for item 4
(`Docs/soneto-implementation-plan-phase3.md` §3.8) purely so the app has *something*
to show in the system tray — a solid-color circle (using the `Accent` light-theme
token color, `#FF3D6BFF`, so it at least isn't an arbitrary unrelated color) with a
white outline, 32x32, PNG-in-ICO format.

**This is not real branding/visual identity.** No app icon or brand design exists
anywhere in this project yet, and none is called for anywhere in the Phase 3 plan.
Replacing this with a real designed icon is out of this item's scope and someone
else's future decision, not a design choice made here.
